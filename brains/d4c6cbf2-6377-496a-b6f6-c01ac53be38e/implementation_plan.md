# LG 노트북 정밀 터치패드 최적화 계획서

배현명 주인님의 노트북(LG Electronics 15U50P-GR3DK)에 탑재된 **Synaptics 정밀 터치패드(Precision Touchpad)**의 현재 동작 상태를 정밀 진단하였으며, 반응성 극대화 및 조작 편의성을 위한 최적화 계획을 수립하였습니다.

---

## 1. 현재 터치패드 진단 결과

- **장치 모델**: Synaptics I2C 정밀 터치패드 (`ACPI\SYN1B8B`)
- **하드웨어 절전 설정**: `SelectiveSuspendEnabled: 0` (대기 복귀 지연 없음, 양호)
- **주요 소프트웨어/레지스트리 설정 현황**:
  1. **타이핑 중 탭 지연 (AAPThreshold)**: `1` (높은 민감도)
     - *분석*: 키보드 타이핑 직후 터치패드를 건드릴 때 미세한 반응 딜레이가 발생할 수 있습니다. `0`(가장 민감함)으로 변경 시 딜레이가 0이 되어 즉각 반응합니다.
  2. **커서 속도 (CursorSpeed)**: `16 / 20` (신속한 반응으로 잘 설정되어 있음)
  3. **마우스 연결 시 터치패드 유지 (LeaveOnWithMouse)**: `켜짐 (1)`
     - *분석*: USB/블루투스 마우스를 연결했을 때도 터치패드가 켜져 있어 타이핑 중 손바닥 간섭이 생길 수 있습니다.
  4. **마우스 포인터 가속 (MouseSpeed)**: `1` (포인터 정확도 향상 ON)
     - *분석*: 가속도가 켜져 있어 손가락을 빠르게 밀 때 커서가 튀거나 정밀한 클릭 시 미끄러질 수 있습니다.
  5. **스크롤 줄 수 (WheelScrollLines)**: `2줄`
     - *분석*: 윈도우 기본값(3줄)보다 낮아 두 손가락 스크롤 시 화면 이동이 다소 답답하게 느껴질 수 있습니다.

## 2. 제안하는 최적화 프로필

배현명 주인님의 작업 성향에 맞춰 아래 추천 옵션을 적용하거나 원하시는 설정을 지정하실 수 있습니다.

### 옵션 A (강력 추천: 프로 반응성 & 정밀 작업 최적화)
- **탭 딜레이 완전 제거 (`AAPThreshold = 0`)**: 타이핑 직후 터치패드 조작 시 씹힘이나 지연 현상 100% 제거
- **스크롤 반응성 상향 (`WheelScrollLines = 3` 또는 `4`)**: 두 손가락 웹 서핑/코드 스크롤이 부드럽고 시원하게 반응
- **마우스 포인터 가속 최적화**: 1:1 손가락 움직임과 커서 동기화 (원치 않는 오버슈팅 방지)
- **마우스 연결 시 터치패드 끄기 선택 가능**

### 옵션 B (하이브리드 모드: 외장 마우스 연동)
- 옵션 A의 빠른 반응성을 유지하되, **외장 마우스가 감지되면 터치패드를 즉시 자동 비활성화**하여 타이핑 시 오작동 원천 차단

## 3. 사용자 확인 및 선택 사항 (User Review Required)

> [!IMPORTANT]
> 최적화 적용 전 배현명 주인님의 선호도를 확인하고자 합니다.
> 1. **외장 마우스 연결 시**:
>    - [유지] 마우스가 연결되어도 터치패드를 계속 켜 둘까요? (현재 상태)
>    - [자동 끄기] 마우스가 연결되면 터치패드를 자동으로 끌까요? (타이핑 시 오터치 방지)
> 2. **포인터 가속도 (포인터 정확도 향상)**:
>    - [끄기] 손가락 움직임에 정확히 1:1로 반응하도록 가속을 끌까요? (추천)
>    - [유지] 현재 가속도 상태를 그대로 둘까요?
> 3. **스크롤 반응 속도**:
>    - [시원한 스크롤] 1회 스크롤당 3~4줄로 상향할까요? (추천)

## 4. 실행 및 검증 계획 (Verification Plan)

### 변경 사항
- 레지스트리 백업 파일 자동 생성 (`touchpad_backup.reg`)
- 최적화 파워쉘 스크립트 작성 및 즉시 적용 (`SystemParametersInfo` 갱신을 통해 재부팅 없이 즉시 반영)
- 필요 시 Windows 정밀 터치패드 제스처(3손가락, 4손가락 제스처) 안내

### 복구 대책 (Rollback)
- 만약 변경 전 느낌이 더 편하실 경우 언제든 1초 만에 이전 상태로 되돌릴 수 있는 롤백 스크립트를 함께 생성합니다.
