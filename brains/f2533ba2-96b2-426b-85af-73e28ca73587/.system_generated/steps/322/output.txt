대법원 인터넷등기소(iros.go.kr)에서 법인 상호를 검색하는 방법은 다음과 같습니다.

### 1. 상호 검색 방법
인터넷등기소는 공공 서비스로서 직접적인 URL 파라미터를 통한 검색 결과 페이지 공유 기능보다는 **웹사이트 내 메뉴를 통한 단계별 접근**을 권장하고 있습니다[1][2].

*   **접속 경로:** [대법원 인터넷등기소](https://www.iros.go.kr) 접속[3][1]
*   **검색 절차:**
    1.  메인 화면에서 **[법인등기]** 또는 **[열람하기]** 메뉴를 선택합니다[4][5][6].
    2.  검색 옵션에서 **[상호로 찾기]**를 선택합니다[5].
    3.  **관할등기소**를 선택합니다 (전체 등기소 검색도 가능)[4][2].
    4.  **상호명**을 입력한 후 검색 버튼을 누릅니다[4][1].
    *   *주의:* 법인 종류(주식회사 등)를 제외한 **순수 상호명만 입력**하여 검색하는 것이 정확합니다[1][7].

### 2. URL 및 파라미터 관련 정보
*   **직접적인 파라미터 활용:** 인터넷등기소의 검색 기능은 보안 및 세션 관리상의 이유로 특정 검색어를 포함한 URL(예: `?name=...`)을 통해 결과를 직접 호출하는 방식을 공식적으로 지원하지 않습니다. 대부분의 조회 작업은 웹 페이지 내의 동적 폼(Form) 전송을 통해 이루어집니다[8][9].
*   **자동화 및 연동:**
    *   대량 검색이나 시스템 연동이 필요한 경우, 인터넷등기소에서 제공하는 **Open API**를 활용해야 합니다[10].
    *   개인이 자동화 도구를 제작할 경우, 파라미터 조작보다는 `Playwright`, `Selenium`과 같은 브라우저 자동화 도구를 사용하여 웹 UI를 직접 제어하는 방식을 주로 사용합니다[9].

### 3. 참고 사항
*   **동일 상호 확인:** 본점 소재지를 기준으로 관할 등기소 내에 동일한 상호가 있으면 등기가 불가능하므로, 설립 예정 지역의 관할 등기소를 정확히 선택하여 검색하시기 바랍니다[4][11][6].
*   **데이터 활용:** 상호 조회 기능을 포함한 법인 관련 데이터 연동이 필요한 개발자라면 [대한민국 법원 등기정보광장](https://data.iros.go.kr)에서 제공하는 Open API 신청 가이드를 확인하시는 것이 좋습니다[12][10].
