The search for ""pubcUserNo" hometax" returned the following summary:
In the context of the Hometax system—specifically when interacting with its **Business Registration Status Inquiry (사업자등록상태조회)** API—`pubcUserNo` is a field used in the XML payload[1][2][3].

### Key Information:
*   **Purpose:** It is an element within the request map (typically `<map id="ATTABZAA001R08">`) sent to the Hometax server to query the status of a business registration number[2][3][4].
*   **Usage in API Requests:** In most technical implementations for business status verification, this field is left **empty** (`<pubcUserNo/>`)[1][2][5]. It does not typically require a specific value to be provided by the user for standard public status inquiries[3][4].
*   **Technical Context:** It appears as a parameter alongside other fields such as `txprDscmNo` (the business registration number) and `dongCode` (an internal processing code)[1][2][4].

If you are developing an application to check business registration status, you can generally include `<pubcUserNo/>` as an empty tag in your XML request body without needing to populate it with specific user data[3][5][6].
