The search for "홈택스 사업자등록상태조회 python" returned the following summary:
홈택스 사업자등록상태(휴폐업 여부 등)를 파이썬으로 조회하는 방법은 크게 **공공데이터포털의 공식 API를 활용하는 방법**과 **웹 스크래핑(자동화)을 이용하는 방법**으로 나뉩니다.

### 1. 공공데이터포털 API 활용 (권장)
가장 안정적이고 공식적인 방법입니다. 공공데이터포털에서 제공하는 '국세청_사업자등록정보 진위확인 및 상태조회 서비스'를 사용합니다.

*   **진행 절차:**
    1.  [공공데이터포털](https://www.data.go.kr)에 회원가입 후 로그인합니다.
    2.  '국세청_사업자등록정보 진위확인 및 상태조회' 서비스를 검색하여 활용 신청합니다.
    3.  승인 후 '마이페이지'에서 발급받은 **인증키(Service Key)**를 확인합니다.
*   **파이썬 활용:**
    *   `PublicDataReader`와 같은 라이브러리를 사용하면 복잡한 HTTP 요청 코드 없이 간편하게 구현할 수 있습니다[1][2].
    *   **예시 코드 구조:**
        ```python
        from PublicDataReader import Nts
        service_key = "발급받은_인증키"
        api = Nts(service_key)
        
        # 조회할 사업자번호 리스트 등을 데이터프레임으로 준비
        # result = api.get_status(df) # API 명세에 따라 호출
        ```

### 2. 웹 스크래핑 (Selenium 활용)
API 사용이 어렵거나, 특정 상황에서만 필요한 경우 Selenium 라이브러리를 사용하여 홈택스 웹사이트에서 직접 조회하는 방식을 사용하기도 합니다[3][4].

*   **주의사항:** 
    *   홈택스 사이트 구조가 변경되면 코드를 수정해야 합니다.
    *   너무 빈번한 요청은 IP 차단을 당할 수 있으므로 `time.sleep()` 등을 활용해 조회 간격을 충분히 두어야 합니다[3][4].
*   **방법:** `selenium`을 이용해 브라우저를 띄우고, 홈택스 사업자등록상태조회 페이지에 접속하여 사업자번호를 입력하고 조회 버튼을 클릭하는 과정을 자동화합니다[3].

### 3. 상용 API 서비스 이용
대량의 데이터를 실시간으로 안정적으로 조회해야 한다면, 별도의 API 중계 서비스(팝빌, 바로빌 등)를 이용하는 방법도 있습니다[5][6].

*   **장점:** 국세청 API보다 연동이 쉽고, 안정적인 SDK를 제공하며 오류 처리 등이 잘 되어 있습니다[7].
*   **단점:** 사용량에 따른 과금이나 별도 계약이 필요할 수 있습니다[8].
