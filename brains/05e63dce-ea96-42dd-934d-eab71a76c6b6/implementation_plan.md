# 엑셀 파일(office_example) 수식 오류 수정 계획

사용자께서 말씀하신 'Office Example' 엑셀 파일(최신 버전: `office_example_오류테스트.xlsx`)에서 발견된 수식 오류들을 수정합니다.

## 발견된 주요 오류

### 1. '직원정보' 시트
*   **구분(M열):** 날짜와 문자열을 직접 빼거나 잘못된 산술 연산을 수행하는 수식이 작성되어 있어 `#VALUE!` 오류가 발생합니다.
    *   *기존:* `=IF(AND(("2026-05-12")-E2/365,G2="사원"),"주니어","시니어")`
*   **나이대(N열):** `IFS` 함수가 일부 버전에서 `#NAME?` 오류를 일으킬 수 있으므로 호환성을 위해 `IF` 중첩으로 변경을 검토합니다.
*   **기타(O열):** 행마다 수식이 일관되지 않고 제각각으로 들어가 있습니다.

### 2. '복지몰구매내역' 시트
*   **주소(E열):** `INDEX/MATCH` 함수 사용 시 참조하는 헤더 행의 주소가 절대 참조($)로 고정되지 않아, 아래 행으로 갈수록 잘못된 범위를 참조하여 `#N/A` 오류가 발생합니다.
    *   *기존:* `MATCH($E$1, 직원정보!$A2:$I2, 0)` (행 번호가 계속 변함)

## 제안하는 수정 사항

### [직원정보] 시트 수정
*   **구분(M열):** 입사일로부터 현재(2026-05-12 기준)까지의 근속 연수를 계산하여 5년 미만인 '사원'을 '주니어'로 분류하도록 수정합니다.
    *   *수정:* `=IF(AND((DATEVALUE("2026-05-12")-E2)/365.25 < 5, G2="사원"), "주니어", "시니어")`
*   **나이대(N열):** 호환성을 높인 수식으로 정리합니다.

### [복지몰구매내역] 시트 수정
*   **주소(E열):** `MATCH` 함수의 범위를 헤더 행(`$A$1:$I$1`)으로 고정하여 모든 행에서 올바른 열 번호를 찾도록 수정합니다.
    *   *수정:* `=INDEX(직원정보!$A$1:$O$21, MATCH(A2, 직원정보!$A$1:$A$21, 0), MATCH($E$1, 직원정보!$A$1:$O$1, 0))`

## 검증 계획
1. 수정된 수식을 적용한 `office_fixed.xlsx` 파일을 생성합니다.
2. 각 시트에서 오류(#VALUE!, #N/A 등)가 사라지고 올바른 값이 출력되는지 확인합니다.
3. 수정된 파일을 사용자의 Downloads 폴더에 저장합니다.
