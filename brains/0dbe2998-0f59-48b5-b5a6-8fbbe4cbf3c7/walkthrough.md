# 전원 설정 고성능 모드 변경 금지 적용 Walkthrough

AetherOS 데스크톱의 환경 설정(Settings) 앱에 전원 관리 기능을 추가하고, 사용자가 "고성능(High Performance)" 모드로 변경하지 못하도록 제한하는 기능을 구현하였습니다.

## 변경 사항 요약

### 1. [app.js](file:///c:/Users/lg/fix/public/app.js)

* **전원 모드 상태 관리 추가**: global state(`state` 객체)에 `activePowerMode` 속성을 추가하였습니다. (기본값: `'balanced'`, `localStorage`로부터 불러옴)
* **전원 설정 탭 레이아웃 정의**: 환경 설정 앱에 "전원 설정" 탭 메뉴 버튼과 해당하는 탭 화면(Pane)을 추가하였습니다.
* **동적 전원 카드 및 잠금 제한 렌더링**:
  * 세 가지 전원 모드를 지원합니다: `최고의 전원 효율성` (Economy), `균형 조정` (Balanced), `고성능` (Performance, Restricted).
  * `고성능` 옵션은 관리자 보안 정책에 의해 변경할 수 없도록 카드에 `disabled restricted` 클래스를 부여하고 `[제한됨]` 잠금 뱃지를 표시합니다.
* **고성능 변경 동작 방지 및 경고 노출**:
  * 사용자가 `고성능` 카드를 클릭했을 때 경고 알림(`alert`)창을 통해 제한 사실을 안내하고, 선택 상태가 바뀌지 않고 기존 모드(예: 균형 조정 또는 최고의 전원 효율성)를 유지하도록 예외 처리했습니다.

### 2. [style.css](file:///c:/Users/lg/fix/public/style.css)

* **잠금 뱃지 스타일 정의 (`.badge-restricted`)**: 잠금 아이콘과 경고 텍스트를 담는 붉은색 테두리와 옅은 배경의 뱃지 스타일을 추가하여 시각적 직관성을 향상했습니다.
* **선택 불가 카드 스타일 정의 (`.power-card.disabled`)**: 선택할 수 없는 카드는 `opacity: 0.55`, `cursor: not-allowed` 스타일을 부여하여 hover 시 반응하지 않도록 시각적 비활성 상태를 제공합니다.

## 검증 결과 및 확인 방법

1. **환경 설정 진입**: 데스크톱 화면에서 `환경 설정` 앱을 더블 클릭하여 실행하면 왼쪽 탭 최하단에 **배터리 충전 아이콘(battery-charging)을 포함한 전원 설정** 버튼이 표시됩니다.
2. **모드 변경 확인**: 
   * `최고의 전원 효율성`이나 `균형 조정` 카드를 선택하면 선택 효과(푸른빛 테두리 및 그림자)가 정상 이동하며 내부 상태(`state.activePowerMode`)가 업데이트됩니다.
   * `고성능` 모드를 클릭하는 경우, 브라우저 경고로 **"고성능 모드는 시스템 그룹 정책에 의해 제한되었습니다. 관리자에게 문의하세요."**가 노출되고 설정이 반영되지 않습니다.
