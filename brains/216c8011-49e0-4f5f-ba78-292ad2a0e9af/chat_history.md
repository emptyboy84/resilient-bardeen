* **웹 브라우저(Edge, Chrome 등) 종료**: 실행 중인 브라우저 창을 모두 닫고 엑셀에서 다시 복사(Ctrl+C)를 시도해 봅니다.

### 2단계: 윈도우 클립보드 검색 기록 기능 끄기 (추천)
윈도우 10/11의 클립보드 저장 기능이 엑셀과 충돌하는 경우가 많습니다.
1. 키보드의 **`시작(Windows 로고) 키 + I`**를 눌러 **[설정]** 창을 엽니다.
2. **[시스템]** -> **[클립보드]** 메뉴로 이동합니다.
3. **[클립보드 검색 기록]** 항목이 **[켬]**으로 되어 있다면, 이를 **[끔]**으로 변경합니다.

1. 엑셀을 실행합니다.
2. 홈 탭 좌측 상단에 있는 **[클립보드]** 글자 오른쪽 옆의 **작은 화살표(대각선 모양 아이콘)**를 클릭하여 클립보드 작업 창을 엽니다.
3. 클립보드 창 하단의 **[옵션]** 버튼을 클릭합니다.
4. 나열되는 옵션 중 체크되어 있는 항목들을 **모두 체크 해제**합니다.

### 4단계: 엑셀 안전 모드로 실행하여 추가 기능 확인하기
특정 추가 기능(Add-ins)이 충돌을 일으키는지 확인하는 방법입니다.
1. **`Windows 키 + R`**을 눌러 [실행] 창을 엽니다.
2. `excel /safe` 라고 입력한 뒤 엔터를 누릅니다.
