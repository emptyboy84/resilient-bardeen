### 1. Claude 서브에이전트 구축 및 활용 총정리

복잡한 개발 작업을 AI에게 지시할 때 대화가 길어지면 앞선 맥락을 잊거나 결과가 뒤죽박죽되는 문제를 해결하기 위해 도입된 기능입니다[1].

* **서브에이전트란?**[3][4]
  * 메인 대화창과 완전히 분리된 **독립된 컨텍스트 윈도우**를 가진 전문 AI 어시스턴트입니다[3][4].
  * 작업이 끝나면 중간 과정의 지저분한 로그나 탐색 내용은 격리하고, **핵심 결과와 인사이트(요약)만 메인 대화로 반환**합니다[3].
* **핵심 원리 및 구조**[1][3]
  1. **작업 위임:** 메인 AI가 상황을 판단해 적절한 서브에이전트를 호출합니다[1][4].
  2. **독립 실행:** 각 에이전트에 부여된 시스템 프롬프트와 도구 제한(Tool Allowlist)에 따라 독립적으로 코드를 탐색·테스트·리뷰합니다[3][5].
  3. **결과 반환:** 요약된 결과만 주 대화창으로 돌아와 컨텍스트 낭비를 막아줍니다[3].
* **구축 및 설정 방법**[3]
  * `.md` 파일 형식 하나로 정의할 수 있으며, 전역(`~/.claude/agents/`) 또는 프로젝트별(`.claude/agents/`) 폴더에 저장해 사용합니다[3].
  * **작성 예시:**
    ```markdown
    ---
    name: swift-reviewer
    description: swift 코드 품질 리뷰 전문가. 코드 변경 후 즉시 사용.
    tools: read, grep, glob
    ---
    너는 10년 차 시니어 iOS 개발자임. 다음 원칙으로 코드를 리뷰함...
    ```
  * **활용 노하우:** 에이전트 자동 호출의 트리거가 되는 `description` 필드를 "언제 나를 호출해야 하는지" 명확하게 작성하는 것이 핵심입니다[6].

### 2. 구글 "또 앞서가네요" — 안티그래비티 (Google Antigravity)

기존의 코드 보조 도구(Cursor, VS Code 등)를 넘어 **에이전트 우선(Agent-First) 패러다임**을 내세워 출시된 구글의 통합 에이전트 개발 플랫폼입니다[7][8].

* **안티그래비티의 핵심 특징**[2][8]
  * **에이전트 매니저(관리자 보기):** 코드를 고치는 편집기 화면이 중심이 아니라, 여러 AI 에이전트가 병렬로 코딩, 조사, 테스트를 수행하는 과정을 모니터링하고 조율하는 '관제 센터' 역할을 합니다[8][9].
  * **아티팩트(Artifacts) 생성:** 에이전트가 작업 목록, 구현 계획, 브라우저 녹화 및 실행 화면 등 검증 가능한 결과물을 눈에 보이는 형태로 만들어 신뢰도를 높입니다[8].
  * **다양한 모델 지원:** 기본 Gemini 모델뿐만 아니라 프로젝트 성격에 맞게 Claude, GPT 계열 모델까지 유연하게 선택·조합하여 활용할 수 있습니다[10][8].
* **제공 형태**[7][2]
  * 독립형 데스크톱 앱(Antigravity Desktop), 기존 IDE 확장 프로그램, CLI 등 개발자 환경에 맞춰 유연하게 도입할 수 있도록 생태계가 구축되어 있습니다[7][2].
