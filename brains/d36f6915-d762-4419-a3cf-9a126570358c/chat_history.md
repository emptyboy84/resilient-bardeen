### 개선 사항 요약
1. **델타 누적 감지 도입 (뻑뻑함 근본 해결)**
   * **원인**: 이전 코드에서는 터치패드 미세 쓸기 시 발생하는 잘게 쪼개진 휠 이벤트(`deltaX`)를 각각 별개로 보아, 단일 이벤트 강도가 매우 강할 때만( violent swipe ) 동작했습니다. 이로 인해 일반적인 빠르기의 부드러운 스와이프는 모두 무시되어 뻑뻑하게 느껴졌습니다.
   * **수정**: 고주파로 잘게 들어오는 휠 이벤트들의 델타 값을 누적하여 합산(`accumulatedDeltaX`)하도록 변경했습니다. 덕분에 살며시 손가락을 쓸어도 임계값에 부드럽게 도달하며 자연스럽게 화면이 전환됩니다.
2. **쿨다운 시간 단축 & 민감도 필터 개선**
   * 화면 전환 후 대기해야 하는 쿨다운(잠금 시간)을 **800ms에서 600ms로 조절**하여 연속 스와이프 반응 속도를 한층 개선했습니다.
   * 가로/세로 방향성 판정 비율을 `2.0배`에서 **`1.5배`로 완화**하여 완전한 가로 일직선이 아닌 자연스러운 대각선 쓸기 시에도 제스처가 잘 먹히도록 개선했습니다.
3. **방향 역전 및 시간 만료 초기화**
   * 사용자가 스와이프를 하다가 멈추거나(`150ms` 경과), 스와이프 방향을 도중에 바꾸면 누적 수치를 깔끔하게 리셋하여 의도치 않은 오작동을 완전히 걸러내도록 설계했습니다.
4. **터치스크린(모바일) 스와이프 연동**
   * 터치패드 외에도 모바일 기기나 터치 모니터에서 바탕화면을 손가락으로 가로 드래그 시 가상 화면이 자연스럽게 연동 전환되는 Touch Event 제스처를 새롭게 추가했습니다.

   * 현재 `FourFingerLeft` / `Right`가 `4`로 되어 있어, 실제 Windows 가상 데스크톱을 넘기려면 **손가락 4개**를 동시에 대고 크게 쓸어야 작동합니다. 4손가락 제스처는 물리적으로 매우 뻑뻑하고 힘들게 느껴질 수 있습니다.

2. **터치패드 민감도 (중간 수준)**:
   * `AAPThreshold`가 `2`(중간 민감도)로 되어 있어, 키보드를 치고 난 직후나 미세한 터치 시 Palm Rejection(손바닥 닿음 방지) 딜레이 때문에 터치가 즉각 반응하지 않고 뻑뻑하게 멈칫거릴 수 있습니다.
3. **커서 속도 (12 / 최대 20)**:
   * 현재 커서 속도가 중간 값에 준하는 `12`로 되어 있어 다소 느리게 느껴질 수 있습니다.
