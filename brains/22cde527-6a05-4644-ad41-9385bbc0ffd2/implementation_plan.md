# [전수 재검증 계획] 결측 사업체 대상 전수 재검증 및 추가 발굴 계획

## 개요
사용자(배현명 님)의 지시에 따라, **"오래 걸려도 좋으니 모든 가용 가능한 수단을 총동원하여 처음부터 끝까지 전수 재검증하고 모든 데이터의 출처를 명확히 남기는 작업"**을 수행합니다.

* **전체 대상**: 원본 데이터 2,313개 행 중 사업자번호가 누락되었던 **총 421개 기업**
  * 현재 복원 완료: **150개** (Bizno 등 교차 검증 완료)
  * 현재 미복원 공란: **271개** (기존 1차 검색 시 미발견)
* **목표**:
  1. 기존 150개 업체 전수 재검증 (사업자번호, 설립연월, 대표자, 유선연락처, 팩스, 종사자수, 폐업일자, 데이터 출처 URL 100% 실사)
  2. 미복원 271개 업체에 대해 다중 검색 엔진 및 공공 DB를 통한 전수 심층 탐색 (네이버, 공정위 통신판매사업자, 비즈노, 나이스비즈인포, 나라장터, 특허청 KIPRIS 등)
  3. 매출액(`24년 매출액`, `25년 매출액`)에 대해 공공 조달/DART/채용 포털 등 공개 가용 여부 전수 탐색 및 출처 기록
  4. 모든 추가/수정 데이터는 엑셀에 **빨간색 굵은 글씨(`#FF0000`)**로 반영하고 원본 파일(`.xlsx`, `.csv`)에 직접 덮어쓰기

## User Review Required

> [!IMPORTANT]
> **검증 및 매칭 원칙 (Zero Hallucination)**
> 1. **3중 일치 원칙**: 상호명 + 대표자 성함 + 부산 관할 주소(시군구/도로명) 중 2가지 이상이 명확히 일치하는 경우에만 유효 데이터로 확정합니다.
> 2. **유효 사업자번호 체크섬 검증**: 국세청 10자리 가중치 알고리즘 검증 통과 필수.
> 3. **출처 URL 필수 기재**: 실제로 브라우징 및 조회가 가능한 검증된 URL만 기재하며, 가짜 링크나 추정치는 일체 배제합니다.
> 4. **매출액 취급**: 공공(DART, 나라장터 등) 및 포털에 실제 공개된 실적에 한해서만 반영하며, 비공개 개인사업자의 경우 허위 숫자를 지어내지 않고 합법적 비공개 원칙을 준수합니다.

## 세부 수행 계획

### 1단계: 기존 150개 복원 기업 전수 교차 재검증
- **대상**: 1차 복원된 150개 기업
- **검증 항목**:
  * 사업자번호 유효성 및 국세청 상태 (계속사업자 vs 폐업자)
  * 설립연도 / 설립월
  * 대표자 성함 일치 여부
  * 유선 연락처 (전화번호 / 팩스번호)
  * 종사자수 (25년 기준)
  * 폐업일자 (폐업 업체의 경우)
  * 데이터 출처 URL 실제 접속 및 데이터 존재 여부 전수 확인

### 2단계: 미복원 271개 기업 대상 다중 가용 수단 전수 심층 탐색
- **대상**: 현재 공란으로 남아 있는 271개 기업
- **가용 검색 수단 및 데이터베이스**:
  1. **네이버 검색 API / 웹 크롤러**: `상호명 + 대표자명 + 부산`, `상호명 + 도로명/지번 주소` 조합 쿼리
  2. **비즈노(Bizno.net) 다중 키워드 검색**: 상호명 변형(띄어쓰기, 주식회사 유무, 영문/한글) 검색
  3. **공정거래위원회 통신판매사업자 공개 DB**: 전자상거래/온라인 콘텐츠 사업자 대조
  4. **NICE Bizinfo / K-Report 요약 정보**: 기업 기본정보 매칭
  5. **조달청 나라장터(G2B) 및 공공데이터포털**: 부산 지역 입찰/조달 등록 업체 매칭
  6. **특허청 KIPRIS / 한국저작권위원회**: 디자인/캐릭터/소프트웨어 출원인 정보 매칭
- **결과 분류**:
  - `확정 매칭`: 3중 일치 확인 시 즉시 엑셀/CSV 반영
  - `유사 매칭 / 확인 불가`: 확실한 근거가 없는 경우 무리한 추정 배제

### 3단계: 매출액(`24년 매출액`, `25년 매출액`) 공개 데이터 전수 조사
- 복원 대상 기업들에 대해 금융감독원 DART, 조달청 공공데이터, 채용 플랫폼(사람인/잡코리아)에 2024~2025년 매출액이 공시되어 있는지 전수 쿼리
- 확인되는 기업은 금액 및 출처 기재, 비공개 소상공인은 실태조사 조사원 유선 면접용으로 공란 유지

### 4단계: 최종 산출물 갱신 및 보고서 생성
- **엑셀(`.xlsx`)**: `기존행번호` 유지, 새로 복원된 모든 셀 빨간색 굵은 글씨 서식 적용, 틀 고정 및 필터 유지
- **CSV(`.csv`)**: UTF-8 with BOM 인코딩으로 동일 반영
- **감사 보고서(Audit Report)**: 전체 421개 대상의 기업별 검증 결과 및 출처 링크 목록 산출물 문서로 기록
